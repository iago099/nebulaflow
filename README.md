# NebulaFlow — Gestão Visual de Projetos

Aplicação web moderna e responsiva inspirada no Trello, projetada com **React 18**, **Tailwind CSS**, **Framer Motion** e **Lucide Icons**.

## Como Publicar no GitHub Pages (Grátis)

1. Crie um novo repositório no [GitHub](https://github.com/new) (ex: `nebulaflow`).
2. Envie o arquivo `index.html` e `favicon.svg` (pelo próprio site do GitHub em **Add file → Upload files** ou via Git no terminal).
3. No repositório do GitHub, vá em **Settings → Pages**.
4. Em **Build and deployment → Branch**, selecione **`main`** (pasta `/ (root)`) e clique em **Save**.
5. Em 1 minuto seu site estará online no link `https://seu-usuario.github.io/nebulaflow/`!
